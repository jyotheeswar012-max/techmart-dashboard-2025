# 🛍️ TechMart Inc. - Business Performance Dashboard 2025

![Python](https://img.shields.io/badge/Python-3.9%2B-blue) ![Plotly](https://img.shields.io/badge/Plotly-5.x-orange) ![License](https://img.shields.io/badge/License-MIT-green)

Interactive business analytics dashboard tracking **$5.3M+ sales**, **9,353 transactions**, **1,198 customers** across 365 days (Jan–Dec 2025).

## 🔗 Live Dashboard
👉 **[View Live Dashboard](https://jyotheeswar012-max.github.io/techmart-dashboard-2025/)**

## 📊 Dashboard Features
- 📈 Monthly Revenue & Profit Trends
- 🏷️ Product Category Performance
- 👥 Customer Segment Analysis
- 🌍 Regional Sales Breakdown
- 💳 Payment Method Distribution
- 📦 Top Products by Revenue
- 🔖 Discount Impact Analysis
- ⭐ Customer Rating Distribution

## 🛠️ Tech Stack
| Tool | Purpose |
